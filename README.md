# 小傩面找身份 · 翻页阅读基础版

先完成图片与视频的翻页阅读，后续按作者的新需求逐步加入交互和声音。

## 直接查看

聊天中的文件面板不是网站托管：ZIP不一定支持预览，单独预览多文件项目的HTML可能丢失相对路径中的CSS、脚本和媒体，导致只显示默认文字。应下载完整文件到电脑，或使用实际的网页服务查看。

为便于先确认阅读效果，另提供“单文件试读版.html”：图片、CSS和翻页脚本全部内嵌，26页和三种结尾可用，不含视频。构建命令为 `python scripts/build_single_file.py`（生成时需要Pillow；阅读时不需要Python）。此单文件已通过浏览器内嵌内容测试，验证翻页和目录时没有外部文件或网络请求；聊天预览是否允许运行脚本仍由客户端决定。

下载“翻页绘本预览版.zip”，完整解压后，用 Chrome 或 Edge 打开里面的 `index.html`。不要只取出 HTML，也不要在压缩包内部直接打开；`images`、`videos`、`lib` 等文件夹需要保留在旁边。

当前包含：26 个故事页、上一页/下一页、左右方向键、翻页动画、目录、页码跳转、静态/视频模式、视频重播、三套结尾外观、当前浏览器中的阅读位置保存。

默认显示静态画面，点击“让画面动起来”后，当前页播放静音视频。翻页时暂停视频并显示插画，停稳后从头播放新页；不自动跳到下一页。打开目录、切换到后台时暂停视频。声音、剧情热点和小游戏尚未加入。

“结尾外观”目前用于检查三套素材，不是最终故事里的选择交互。切换后第21–25页同步更新，正文为可编辑工作稿。

## 开发与构建

需要 Node.js 20.19+ 或22.12+，当前云环境使用24。

```bash
npm ci --cache /workspace/.cache/npm
npm run dev -- --port 4173
```

生成可独立打开或部署到静态网站的文件：

```bash
npm run build
```

输出位于 `dist/`。开发服务器只用于开发；最终发布整个 `dist/` 文件夹。当前没有公开发布网址。

## GitHub Pages 固定预览

网站构建文件保存在 `gh-pages` 分支，源代码在 `main`。首次开启时，在 GitHub 仓库进入 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 **gh-pages**，目录选 **/(root)**，点击 **Save**。部署成功后使用该页面显示的网站地址。

后续修改源码后，先提交并推送 `main`，再运行下面的命令更新同一个预览网站：

```bash
python scripts/publish_pages.py
```

这个命令会构建网站、提交构建结果并推送到 `gh-pages`；不切换当前分支、不创建工作树、不强制覆盖远程分支。需要已有 Git 推送权限。发布分支不包含原图、原始HEVC视频或开发依赖。

## 修改位置

- `story.js`：页序、标题、文字与各分支素材名。
- `app.js`：翻页、视频和阅读控制。
- `styles.css`：界面与手机布局。
- `public/images/`：从原图生成的 WebP 网页副本；原图保留。
- `public/videos/`：已转换的 H.264/AAC MP4 网页副本。
- `原图/`、`对应视频/`：保留的原素材。
- `素材说明/`：命名对照与视频转换说明。

没有依赖在线字体、CDN或后台服务。开发依赖需要联网安装，打包后的阅读文件均位于本地。

## 开源组件

使用 [StPageFlip 2.0.7](https://github.com/Nodlik/StPageFlip)，MIT 许可。随网页保留 `lib/StPageFlip-LICENSE.txt`。本项目的插画和视频不因使用该组件而自动适用 MIT 许可。

单页阅读使用其 portrait 模式（每张画面仍为横图）。视频使用 HTML 页面嵌入；翻动时使用静态图避免播放与页面变换同时发生。
